# Security policy

## Supported versions

Only the latest release gets security fixes.

## Reporting a vulnerability

Please do not report security problems in public issues, pull requests or
discussions.

Report them privately through GitHub instead:

1. Go to the [Security tab](https://github.com/martinthommesen/nettvern-check/security)
   of this repository.
2. Select **Report a vulnerability**.
3. Describe the problem, how to reproduce it, and the impact you expect.

You should get a first response within 7 days. Once the problem is confirmed,
a fix is released as soon as practical and the advisory is published with
credit to you, unless you ask to stay anonymous.

## Scope

In scope: the `nettvern-check` program, its build and release process, and the
files published in this repository's releases.

Out of scope: Telenor's services themselves, including how Nettvern, Nettvern+
or SafeZone decide what to block. Report those to Telenor.
